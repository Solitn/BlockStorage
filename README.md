# BlockStorage

把文件或整个目录加密后分块存进一个 `.block/` 仓库，需要时再按原来的目录结构取出来。

- 单文件、整目录都能存，空目录也会保留
- 加密存储：密码解锁，数据块逐个校验，改一个字节就能发现
- 三级存放：小文件直接进索引，中等文件走 4 KiB 块，大文件走 256 KiB 块
- 删除后的空洞会被复用，仓库不会越用越肿
- 只有一个 exe，不需要另装运行库
- 自带交互式浏览器 `brow`：边看、边加、边导

## 快速开始

```
init -p<密码>              # 在当前目录建仓库（不带 -p 则只做混淆，不保密）
add <文件或目录> [路径]     # 存入
ls                         # 查看
get <内部路径> [目标]       # 取出
```

一个完整例子：

```
init -pMyPass
add D:\photos /backup/photos
ls /backup -r
get /backup D:\restore
```

取出后的目录是 `D:\restore\backup\photos\...`，和存进去时一致。

## 命令

| 命令 | 作用 |
| --- | --- |
| `init [-p<pwd>] [-s<salt>]` | 创建仓库，`-p` 设置密码 |
| `load -p<pwd>` | 解锁仓库（每次启动都要，免密仓库除外） |
| `add <src> [path] [-r]` | 加文件或目录；`path` 以 `/` 结尾表示放进该目录 |
| `import <dir> [path]` | 镜像一个目录（含空目录），等同于 `add <dir>` |
| `brow [path]` | 交互式浏览、快速加入、导出 |
| `get <path> [target]` | 取出文件或整个目录，保留原层级 |
| `ls [path] [-r]` | 列出目录，`-r` 递归 |
| `rm <path> [-r]` | 删除，目录要加 `-r` |
| `out [path]` | 查看或设置默认导出位置 |
| `statu` | 仓库状态、空间用量、文件与目录数量 |
| `delete` | 删除整个仓库（不可恢复） |
| `help [command]` | 命令列表 / 单条说明 |

仓库内部路径统一用 `/` 分隔，例如 `/docs/2024/a.txt`。

## 交互式浏览器 `brow`

`brow` 进入后提示符变成 `brow:/当前目录>`，输入 `quit` 回到主提示符。

| 子命令 | 作用 |
| --- | --- |
| `ls [-r]` | 看当前目录 |
| `cd <path>` / `up` / `pwd` | 进入 / 返回上级 / 显示当前目录 |
| `lls [path]` / `lcd <path>` / `lpwd` | 看本地目录 / 切换 / 显示 |
| `add [本地路径] [名称]` | 快速加入，默认放进当前目录 |
| `get [路径] [本地目录]` | 导出，保留原有层级 |
| `rm <名称> [-r]` | 删除 |
| `help` / `quit` | 帮助 / 退出 |

常用流程：

```
brow                  # 从根目录开始
lls D:\photos         # 先看看本地
lcd D:\photos
ls                    # 再看看仓库
add 2026              # 把本地 2026 目录加到当前仓库目录
get /docs D:\restore  # 导出
quit
```

## 导出位置规则

默认导出到「当前目录下的 `extract`」，也可以自己指定。无论哪种，都保留仓库里的完整层级。

- 整个目录：`get /archive D:\restore` → `D:\restore\archive\tree\...`
- 不写目标：写到默认位置，路径同样是 `<默认位置>/<完整内部路径>`
- 单个文件：目标已是目录 → 放进 `<目标>/<完整内部路径>`；目标不存在 → 当作文件名
- 空目录也会被创建

默认位置的优先级：环境变量 `BLOCKSTORAGE_OUT` → `out` 设置的路径 → `<当前目录>\extract`。
`out` 的设置在仓库加锁时看不到。

## 仓库里有什么

```
.block/
├── idx          索引（加密）：目录结构 + 导出位置设置
├── key          解锁信息（免密仓库为空文件）
├── data.blk     大块数据区（256 KiB 一块）
├── data.small   小块数据区（4 KiB 一块）
└── bit          块的使用情况与文件内部串联
```

- 没有单独的配置文件，也没有位图文件
- 目录结构是一棵树：`ls` 可以进任意一层，`-r` 展开全部
- 小于 1 KiB 的文件直接放在索引里，不占数据块

## 使用约定

- 重名判断不区分大小写：`Duplicate path: X conflicts with existing Y`
- 同名目录可以合并，文件与目录不能互相覆盖
- 一次导入会在写入前整体检查，有冲突就整批放弃，不会写一半
- 删除目录必须加 `-r`
- 中文路径、中文文件名都支持
- 仓库格式不兼容旧版本，旧仓库需要重新 `init`

## 常见问题

**忘记密码？** 没有找回途径，索引和数据都无法解开。

**`get` 提示 `No such file or directory`？** 先用 `ls -r` 看完整路径，注意大小写和层级。

**`rm` 提示 `is a directory ... use rm -r`？** 目录要加 `-r`。

**仓库加锁了？** 先 `load -p<密码>`。免密仓库不需要。
